## Input and Output Files Documentation

---

### 1. Input Files

#### **Raw FASTQ Files (`R1`, `R2`)**

* **Description:** High-throughput short-read sequencing data in FASTQ format representing paired-end reads (Forward read: `R1`, Reverse read: `R2`).
* **Structure & Content:** Text-based format consisting of four lines per sequence read:
1. **Header:** Begins with `@`, containing the sequence identifier and instrument/run metadata.
2. **Sequence:** Raw nucleotide sequence letters (`A`, `C`, `G`, `T`, `N`).
3. **Separator:** Begins with `+` (optionally repeating the sequence identifier).
4. **Quality Scores:** ASCII-encoded Phred+33 quality scores representing base-calling error probabilities.



#### **Reference Genome (`FASTA`)**

* **Description:** The reference genomic sequence (e.g., human genome assembly) used for read alignment and variant discovery.
* **Structure & Content:** FASTA format containing text-based representation of nucleotide sequences:
* **Header Line:** Begins with `>` followed by the sequence/chromosome name (e.g., `>chr1`).
* **Sequence Lines:** Continuous lines of uppercase or lowercase nucleotide characters representing the genomic sequence.



---

### 2. Intermediate Files

#### **Reference Indexes (`.fasta.bwi/.bwt`, `.fai`, `.dict`)**

* **Description:** Auxiliary lookup files generated from the reference genome to speed up alignment and coordinate tracking.
* **Structure & Content:**
* **BWA Index (`bwa index`):** Binary files (`.amb`, `.ann`, `.bwt`, `.pac`, `.sa`) encoding the Burrows-Wheeler Transform of the reference.
* **FASTA Index (`samtools faidx`):** A `.fai` text file mapping chromosome names, sequence lengths, offset bytes, bases per line, and bytes per line.
* **Sequence Dictionary (`gatk CreateSequenceDictionary`):** A `.dict` text file in SAM header format specifying sequence names, lengths, and MD5 checksums.



#### **Alignment Files (`SAM` / `BAM` / `Analysis-Ready BAM`)**

* **Description:** Binary/Text alignment maps generated after mapping reads to the reference, sorting coordinates, and marking PCR duplicates.
* **Structure & Content:**
* **SAM/BAM format:** Tab-delimited format containing a header section (lines starting with `@`) and an alignment section.
* Key columns include: Query Template Name (`QNAME`), Bitwise Flag (`FLAG`), Reference Sequence Name (`R2`/`CHROM`), 1-based leftmost mapping Position (`POS`), Mapping Quality (`MAPQ`), CIGAR string (`CIGAR`), Sequence (`SEQ`), and Quality (`QUAL`).
* **Analysis-Ready BAM:** Sorted, indexed, and duplicate-marked BAM file.



#### **Variant Call Files (`VCF.gz` / `.tbi`)**

* **Description:** Compressed variant call files produced independently by Freebayes and GATK HaplotypeCaller.
* **Structure & Content:** Tabix-indexed Variant Call Format (`.vcf.gz`):
* **Meta-information lines:** Header lines starting with `##` describing filters, formats, and software parameters.
* **Column Header line:** Starting with `#CHROM` defining mandatory fields: `CHROM`, `POS`, `ID`, `REF`, `ALT`, `QUAL`, `FILTER`, `INFO`, `FORMAT`, and sample columns.
* **Data lines:** Tab-delimited records specifying genomic coordinates, alleles, quality metrics, and sample genotypes.



---

### 3. Output Files

#### **High-Confidence Consensus VCF (`CONS_VCF`)**

* **Description:** A refined variant file outputted by the custom Python script following a strict set-intersection operation on orthogonal caller outputs.
* **Structure & Content:** Valid VCF 4.1/4.2 format containing only those genetic variants mutually discovered and validated across multiple independent callers (minimizing false positives).

#### **Annotated VCF (`ANN_VCF`)**

* **Description:** Functional annotation of the high-confidence variants mapping genomic changes to genes, transcripts, and predicted functional consequences.
* **Structure & Content:** Standard VCF format appended with an expanded `INFO` field (specifically the `ANN` subfield generated by SnpEff) detailing functional impacts, amino acid changes, gene names, and effect severities.

#### **Interactive HTML Report (`REPORT`)**

* **Description:** Comprehensive quality control summary report compiling metrics across the entire workflow.
* **Structure & Content:** Self-contained, interactive HTML file generated by MultiQC. It includes visual graphs and summary tables tracking alignment rates, duplication percentages, insert size distributions, and variant annotation statistics.

---

> [!NOTE]
> All downstream VCF outputs require accompanying index files (`.tbi` or `.csi`) to allow rapid random-access querying by genomic coordinates in subsequent analysis steps.
